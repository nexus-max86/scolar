# Guide d'utilisation — Scolar

Ce guide s'adresse au directeur et au secrétaire/caissier d'une école.

## 1. Démarrer (directeur, une seule fois)

1. **Inscrire l'école** : sur la page d'accueil, « Essai gratuit 30 jours ». Remplissez le nom de l'école, la ville,
   le téléphone, l'année scolaire (ex. 2026-2027) et votre compte directeur. Le logo peut être ajouté plus tard.
2. **Créer les classes** : menu « Classes ». Exemple : *6e primaire*, *1re humanités* (section *Scientifique*).
3. **Définir les frais** : menu « Frais scolaires ». Pour chaque frais : type, libellé, montant, devise (USD ou CDF),
   classe concernée (ou toutes) et date limite.
   - Frais mensuels : cochez « créer une échéance par mois » pour obtenir 10 mensualités de septembre à juin.
   - Un frais déjà payé par des élèves ne peut plus changer de montant ; il peut être archivé.
4. **Ajouter les élèves** : un par un (« Inscrire un élève ») ou tous d'un coup avec « Importer Excel » :
   téléchargez le modèle, remplissez une ligne par élève, envoyez le fichier. Les classes manquantes sont créées.
5. **Créer le compte du caissier** : menu « Utilisateurs », rôle « Secrétaire / caissier ».
6. **Personnaliser les reçus** : menu « Paramètres » (logo, préfixe des numéros, mention en bas du reçu).

## 2. Encaisser un paiement (caissier ou directeur)

1. « Encaisser un paiement », cherchez l'élève par son nom ou son matricule.
2. Choisissez le frais : le montant se remplit avec le reste à payer. Modifiez-le pour un paiement partiel.
3. Choisissez le moyen (espèces, M-Pesa, Airtel Money, Orange Money, virement…) et, pour le Mobile Money,
   le numéro de transaction.
4. « Enregistrer et générer le reçu ». Le reçu numéroté s'affiche : **Télécharger le PDF**, **Imprimer**, ou
   **Envoyer par WhatsApp** au parent (le message est déjà rédigé).

Le système refuse un montant supérieur au reste à payer. Un paiement ne peut pas être supprimé : en cas d'erreur, le
directeur ouvre le reçu et clique « Annuler ce paiement » en indiquant le motif. Le reçu reste visible avec la mention
ANNULÉ.

## 3. Suivre l'argent

- **Caisse du jour** : total encaissé par devise, par moyen de paiement et par agent, et les espèces à remettre.
  Le caissier voit ses propres encaissements, le directeur ceux de toute l'école.
- **Impayés** : élèves qui doivent encore de l'argent, par classe. Cochez « date limite dépassée » pour ne voir que
  les retards. Le lien WhatsApp prépare un rappel poli au parent.
- **Paiements** : historique sur une période, filtrable par moyen de paiement, exportable en Excel.
- **Fiche élève** : total à payer, déjà payé, solde, détail par frais et historique des reçus.

## 4. Qui peut faire quoi

| Action | Directeur | Caissier |
| --- | :---: | :---: |
| Inscrire, modifier, rechercher un élève | ✓ | ✓ |
| Encaisser, imprimer un reçu, voir les impayés | ✓ | ✓ |
| Archiver ou transférer un élève | ✓ | |
| Classes, frais scolaires, utilisateurs, paramètres | ✓ | |
| Annuler un paiement | ✓ | |

## 5. Bon à savoir

- Les montants en dollars et en francs congolais sont toujours affichés séparément, jamais convertis.
- En cas de coupure Internet, un bandeau orange s'affiche : attendez le retour de la connexion avant d'enregistrer.
- Quand l'abonnement expire, les données restent consultables mais les nouvelles saisies sont bloquées jusqu'au
  renouvellement.
